# 智能物流3D装箱优化系统演示
# Smart Logistics 3D Bin Packing Optimization System Demo

## 🎯 项目概述

这是一个完整的智能物流3D装箱优化系统，集成了多角色Web界面、实时数据可视化、以及先进的优化算法。系统为物流公司提供了从客户下单到配送完成的全方位管理解决方案。

## 🌟 核心功能

### 1. 多角色用户界面
- **司机端** (`/driver`) - 查看车辆日程、装载方案、运输路径
- **管理层** (`/manager`) - 成本分析、车辆监控、效率报告
- **客户端** (`/customer`) - 货物下单、订单追踪、历史记录
- **演示端** (`/demo`) - 优化算法效果展示

### 2. 3D装载可视化
- 基于Plotly.js的交互式3D装箱展示
- 支持单品类和多品类货物可视化
- 装载率热力图和效率分析
- 实时装载方案预览

### 3. 智能路径优化
- 集成Folium地图的路径可视化
- 多目标路径优化算法
- 实时交通数据集成
- 配送成本和碳排放计算

### 4. 数据分析仪表板
- 实时性能监控
- 成本效益分析
- 装载率趋势图表
- 优化效果对比

## 🚀 快速开始

### 方法1: 使用启动脚本
```bash
python start_demo.py
```

### 方法2: 手动启动
```bash
# 安装依赖
pip install -r requirements.txt

# 启动服务器
uvicorn api.app:app --host 0.0.0.0 --port 8000 --reload
```

### 访问地址
- **主演示页面**: http://localhost:8000/demo
- **司机端**: http://localhost:8000/driver
- **管理层**: http://localhost:8000/manager
- **客户端**: http://localhost:8000/customer
- **管理员**: http://localhost:8000/admin
- **API文档**: http://localhost:8000/docs
