## 🚀 系统启动指南

### 前端开发服务器
```bash
# 进入前端目录
cd A:\MYpython\物流\frontend

# 安装依赖 (已完成)
npm install

# 启动开发服务器
npm run dev
```

**访问地址**: http://localhost:3000
**启动时间**: ~466ms (极快)
**热重载**: ✅ 支持

### 后端API服务
```bash
# 启动后端API (需要单独启动)
python start_api_simple.py
```

**API地址**: http://localhost:8001
**文档地址**: http://localhost:8001/docs
